# AI 기반 일본어 단어·한자 학습 웹 서비스 개발 계획서

## 1. 프로젝트 개요

### 1.1 프로젝트 목적

본 프로젝트는 일본어 학습자가 단어와 한자를 단순히 반복해서 읽는 방식에서 벗어나, **간격 반복(Spaced Repetition), 능동 회상(Active Recall), AI 분석, 이미지 학습, OCR** 등을 활용하여 효율적으로 장기 기억할 수 있도록 지원하는 일본어 학습 웹 서비스 개발을 목적으로 한다.

사용자가 직접 단어를 입력하거나 교재 및 개인 단어장의 사진을 촬영하면 AI가 자동으로 단어를 분석하여 다음 정보를 생성한다.

* 일본어 단어
* 후리가나
* 한국어 뜻
* 품사
* JLPT 난이도
* 관련 한자
* 예문
* 유의어 및 비슷한 표현
* 이미지 또는 기억을 돕는 시각 자료

등록된 단어는 단순히 저장되는 것이 아니라 사용자의 학습 기록에 따라 자동으로 복습 일정이 생성된다.

서비스의 기본 학습 흐름은 다음과 같다.

```text
단어 등록
↓
AI 자동 분석
↓
단어장 저장
↓
오늘의 새 단어 학습
↓
퀴즈
↓
정답 / 오답 기록
↓
다음 복습일 자동 계산
↓
간격 반복 복습
↓
문장 만들기 및 실제 활용
↓
장기 기억 단어로 전환
```

또한 일본의 상용한자 2,136자를 학습할 수 있는 별도의 한자 학습 시스템을 제공하며, 한자와 단어를 서로 연결하여 한자를 실제 어휘 속에서 학습할 수 있도록 한다.

---

# 2. 주요 목표

본 서비스의 주요 목표는 다음과 같다.

1. 일본어 단어를 효율적으로 장기 기억할 수 있도록 한다.
2. 사용자가 직접 만든 단어장을 기반으로 개인화된 학습을 제공한다.
3. 사진 촬영만으로 단어장을 자동 생성할 수 있도록 한다.
4. 일본 상용한자 2,136자를 체계적으로 학습할 수 있도록 한다.
5. 단어와 한자를 서로 연결하여 실제 어휘 중심으로 학습하도록 한다.
6. AI를 활용하여 예문, 설명, 비교 표현 등을 자동으로 제공한다.
7. 사용자의 오답 기록을 분석하여 취약한 부분을 반복적으로 학습하도록 한다.
8. 단순 암기에서 끝나지 않고 직접 문장을 만들어 실제로 사용할 수 있도록 한다.
9. 이미지와 상황을 이용하여 시각적인 기억을 활용할 수 있도록 한다.
10. 장기적으로 개인별 일본어 학습 데이터를 분석하여 맞춤형 학습을 제공한다.

# 3. 핵심 학습 방식

## 3.1 기본 일일 학습 루틴

기본 학습 루틴은 다음과 같이 구성한다.

```text
새 단어 15개 학습
↓
어제 학습한 단어 테스트
↓
3일 전 단어 복습
↓
7일 전 단어 복습
↓
14일 전 단어 복습
↓
틀린 단어 재시험
↓
오늘 학습한 단어 중 3~5개 문장 만들기
```

사용자는 하루 학습량을 직접 설정할 수 있다.

예:

```text
하루 새 단어
5개 / 10개 / 15개 / 20개 / 사용자 설정

하루 목표 학습 시간
10분 / 20분 / 30분 / 60분
```

# 20. AI 문장 만들기 연습

```text

```


```text

友達がわざわざ韓国まで来てくれました。

「〜てくれる」를 사용하면

```

# 64. 서비스의 핵심 차별점

일반적인 단어장 서비스는 다음과 같은 구조가 많다.

```text
단어
↓
뜻
↓
암기
```

본 서비스는 다음과 같은 전체 학습 사이클을 목표로 한다.

```text
사진 / 직접 입력
↓
AI 자동 분석
↓
단어 + 한자 + 예문 + 이미지 연결
↓
간격 반복
↓
다양한 형태의 퀴즈
↓
오답 분석
↓
AI 취약점 분석
↓
문장 만들기
↓
AI 회화에서 실제 사용
↓
장기 기억
```

즉, 단순한 **일본어 단어 저장 서비스가 아니라 사용자가 무엇을 알고 무엇을 잊어버리고 있는지 판단하여 다음 학습을 자동으로 결정하는 일본어 개인 학습 시스템**을 최종 목표로 한다.
